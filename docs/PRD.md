# PRD — Cross-Agent Sync

版本：0.1（基线来自《Cross-Agent Sync 详细开发指导》2026-11-16，用户已确认范围调整）

## 定位

**Local-first 的跨 AI Agent 项目工作空间**——不是新 Agent，不是云盘。为每个项目维护一份独立于厂商的共享上下文；Agent 通过 MCP 与项目规则文件读写；用户在桌面应用里查看、编辑、搜索和管理。

## 解决的问题

同时使用多个 AI Coding Agent 的开发者，切换工具时要重新解释项目背景、技术选型、进度、坑与决策。

## 三类同步对象（不可混谈）

| 子系统 | 内容 | V1 做法 |
|---|---|---|
| **Context Sync** | 项目介绍/架构/规范/任务状态/技术决策/交接记录 | `.agent-sync/` Markdown + MCP 读写 |
| **Conversation Sync** | 会话标题/消息/工具调用摘要 | **导入**统一索引供搜索；不做无损互转 |
| **Project Sync** | 文件变化/Git 状态 | Chokidar 记录事件 + Git 只读展示；不重造 Git |

## V1 范围（已确认）

- **只做 ZCode 与 Codex 两个适配器**。Claude Code、Cursor 后置（接口可扩展）。
- MVP 闭环：**Codex 在项目里（经 MCP）写入上下文与交接 → ZCode（经 MCP）读取并继续工作**。

## 优先级

- **P0**：项目创建/导入/切换、上下文管理、任务管理、MCP 本地服务、ZCode+Codex 接入、文件变化记录、会话导入（至少 ZCode、Codex 各一源）
- **P1**：聊天全文搜索（FTS5）、Git 状态只读、多设备 Git 工作流
- **P2**：云端账号/实时同步、自动编排、自动总结（不做）

## 明确不做

实时双向无损同步所有聊天记录；直接读取所有 Agent 私有数据库做写入；自动控制 Agent 内部记忆；自动合并代码冲突；自动上传云端；同步凭证；未经确认的跨 Agent 任务执行。

## 产品原则

Local-first；用户拥有数据（Markdown/JSON/SQLite 常规格式）；厂商无关（差异进 Adapter）；不覆盖用户配置（检查→备份→diff→确认→原子写）；自动化可审计；安全默认值（只授权明确绑定的目录）。
